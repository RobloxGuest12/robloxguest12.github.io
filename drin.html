DRin

Durian Package Manager — a lightweight, Rust-based command-line package manager interface designed primarily for Ubuntu. One simple command line for everyday package tasks.

Version 0.3.0 · 64-bit AMD/Intel (.deb) · Ubuntu

Package management, simplified.

DRin provides a compact CLI for common package-management tasks, with APT doing the actual system package transactions.

⌘

Simple commands

Install, remove, search, inspect, update, upgrade, and clean packages from the terminal.

⚡

Rust-powered

Built in Rust with a lightweight command-line interface and asynchronous download components.

↓

Download tools

Includes a custom downloader with adaptive concurrency, retries, progress indicators, and SHA-256 verification.

Quick command examples

Run DRin from your Ubuntu terminal. Package-changing operations may request administrator authentication.

Ubuntu terminal
drin -u                      # Update package lists
drin -g                      # Upgrade installed packages
drin -i firefox vlc          # Install packages
drin -r chrome               # Remove a package
drin -s fastfetch             # Search for a package
drin -f virtualbox            # Show package information
drin -c                      # Clean package cache
Compatibility note: DRin 0.3.0 is primarily intended for Ubuntu and currently uses APT / apt-get / apt-cache for package operations. Compatibility with other Debian-based distributions may vary. The custom downloader does not replace APT's package transaction or dependency-resolution system.
