What is Poop.txt?

Poop.txt is a tiny, open-source plain-text file with one job: contain one word. No installation, dependencies, setup wizard, account, or internet connection required.

Features

⚡ Extremely lightweightJust a tiny text file.
📄 Plain textReadable with ordinary text editors.
🌐 Works offlineNo network connection needed to open it.
🧩 No dependenciesNo runtime, installer, or extra packages.

Poop.txt uses plain text, a format supported by a huge range of operating systems and text editors.
